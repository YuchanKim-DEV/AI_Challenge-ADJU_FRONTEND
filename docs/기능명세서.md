[1] 화면 구성

F-01  사용자 선택 화면
 · 체험할 사용자(페르소나)를 카드로 선택
 · 청년(홍길동 23세) / 노년(김순자 68세) 2인
 · 각 카드에 상황 요약 표시
 · 카드 클릭 시 조회 화면으로 전환

F-02  보험 조회 화면
 · 선택한 사용자의 가입 보험을 불러오는 단계
 · 진행 상태를 3단계로 표시
   가입 보험 조회 → 보장 내용 분석 → 대화 준비
 · 조회 완료 후 대화 화면으로 자동 전환
 · 이 시점에 이전 대화 이력을 초기화

F-03  대화 화면
 · 좌측 : 챗봇 대화 영역
 · 우측 : 보험정보 입력 영역
 · 상단 : 선택된 사용자 정보, 사용자 변경 버튼


[2] 대화 기능

F-04  질의응답
 · 입력 : 자연어 질문 (텍스트)
 · 출력 : 답변 + 근거 목록
 · 처리 : 질문 임베딩 → 보험정보·문서 검색 → LLM 답변 생성
 · 평균 응답 3초
 · 전송 : Enter (Shift+Enter 줄바꿈)

F-05  대화 맥락 유지
 · 이전 대화를 서버가 보관하여 후속 질문에 반영
 · "그럼 지금은?" 같이 생략된 표현도 이해
 · 사용자 변경 시 자동 초기화

F-06  답변 서식 표시
 · 표 형태 보장 정보를 실제 표로 출력
 · 제목 / 굵게 / 목록 / 이모지 표시 지원
 · 표가 길면 가로 스크롤 처리

F-07  근거 표시
 · 답변 하단에 참조 문서를 목록으로 표시
 · 파일명, 페이지, 조항, 유사도 점수 포함
 · 클릭 시 원문 일부 확인 가능

F-08  응답 대기 표시
 · 답변 생성 중 입력창 비활성화
 · 대기 애니메이션 표시

F-09  한글 입력 처리
 · 한글 조합 중 Enter 입력 시 전송하지 않음
 · 조합 완료 후 전송 (마지막 글자 유실 방지)


[3] 보험정보 입력 기능

F-10  보험정보 텍스트 입력
 · 입력 : 자유 형식 한국어 텍스트
 · 처리 : LLM이 보험사·상품명·특약·보장금액·계약일을 추출하여 반영
 · 반영 후 변경 이력 기록
 · 이후 질문부터 갱신된 내용 기준으로 답변

F-11  입력 예시 버튼 (프리셋)
 · 사용자별 검증된 예시 문구 2건 제공
   청년 : 수술비특약 가입 / 운전자보험 가입
   노년 : 간병인보험 가입 / 간병비보험 가입
 · 클릭 시 입력창에 자동 입력 (계약일 포함)

F-12  계약일 필수 검증
 · 입력 텍스트에 날짜가 없으면 경고 표시
 · 날짜 없이는 전송 버튼 비활성화
 · 인식 형식 : 2026-09-05, 2026.9.5, 2026년 9월 등
 · 사유 : 계약일 누락 시 보험정보가 정상 저장되지 않음

F-13  무관 입력 안내
 · 보험과 관련 없는 내용 입력 시 안내 팝업 표시
 · 문구 : "가입하신 보험과 관련된 내용을 입력해 주세요"
 · 해당 입력은 저장되지 않음

F-14  전송 이력 표시
 · 입력한 보험정보를 목록으로 표시 (시각 + 첫 줄)
 · 항목 클릭 시 전체 내용 확인
 · 지우기 버튼 제공
 · 페이지 유지 중에만 표시, 새로고침 시 초기화

F-15  반영 결과 안내
 · 반영 성공 시 대화창에 입력 내용과 완료 안내 표시
 · 실패 시 사유 표시


[4] 문서 등록 기능

F-16  보험증권 업로드
 · 입력 : PDF, PNG, JPG, TXT (최대 50MB)
 · 처리 : 문서 파싱 → 청크 분할 → 임베딩 생성 → 벡터 저장
 · 등록 후 질의응답의 검색 대상에 포함
 · 현재 MVP 시연은 텍스트 입력(F-10) 방식으로 진행하며,
   본 기능은 구현 완료 상태로 확장 시 활용

F-17  등록 문서 초기화
 · 특정 사용자의 문서 임베딩 삭제
 · 대화 이력 삭제


[5] 시스템 기능

F-18  사용자 변경
 · 대화 화면에서 다른 사용자로 전환
 · 화면 대화 및 서버 대화 이력 초기화

F-19  보안 연결
 · 공인 인증서 기반 HTTPS 적용
 · 인증서 자동 갱신 (일 2회 확인)

F-20  자동 복구
 · 서버 재부팅 시 서비스 자동 재시작
 · 네트워크 설정 자동 복원

F-21  반응형 화면
 · 화면 너비에 따라 좌우 배치 → 상하 배치로 전환
 · PC 및 모바일 브라우저 지원


[6] 시연 시나리오별 기능 흐름

시나리오 1 · 청년 (보장 만료 확인 후 신규 가입)
 1) F-01 사용자 선택 — 홍길동
 2) F-02 보험 조회
 3) F-04 질문 "목 뒤 종양 수술을 받을 예정인데 수술비 보장을 받을 수 있어?"
    → 수술비특약 2025-12-31 만료, 보장 불가 안내
 4) F-11 프리셋 [수술비특약 가입] 선택
 5) F-10 보험정보 반영
 6) F-05 재질문 "그럼 지금은 수술비 보장이 어떻게 달라졌어?"
    → 이전 보장 없음 → 300만원 보장으로 변경 안내

시나리오 2 · 노년 (보장 공백 확인 후 신규 가입)
 1) F-18 사용자 변경 — 김순자
 2) F-04 질문 "내 보험 중에서 간병인을 사용할 때 보장받을 수 있는 보험이 있어?"
    → 간병 보장 없음 안내
 3) F-11 프리셋 [간병인보험 가입] 선택
 4) F-10 보험정보 반영
 5) F-05 재질문 "새로 가입한 보험까지 포함하면 간병비 보장이 어떻게 달라졌어?"
    → 이전 보장 없음 → 1일 15만원, 연간 180일 한도로 변경 안내
