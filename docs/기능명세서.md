1. MVP 구현 범위
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

가입 보험의 보장 내용을 대화로 확인하고, 신규 가입 보험을 즉시 반영하여
변경된 보장 내용을 다시 안내받는 것까지를 구현 범위로 한다.

포함 범위
 - 사용자(페르소나) 선택 및 가입 보험 조회
 - 가입 보험 기반 자연어 질의응답
 - 답변 근거(출처 문서·조항) 제시
 - 이전 대화를 반영한 후속 질의응답
 - 보험정보 자연어 입력 및 즉시 반영
 - 반영 전후 보장 변화 비교 안내

제외 범위 (본 MVP에서 확인 불가)
 - 회원가입 및 로그인
 - 보험증권 파일 업로드 화면
 - 마이데이터 연계를 통한 보험정보 자동 수집
 - 보험금 청구 지원

2. 주요 기능 목록
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

F-01  사용자 선택
 · 설명 : 체험할 사용자를 카드로 선택한다. 청년(홍길동 23세)과
          노년(김순자 68세) 2인이며, 각 카드에 상황 요약이 표시된다.
 · 화면 : 사용자 선택 화면
 · 상태 : 구현 완료

F-02  가입 보험 조회
 · 설명 : 선택한 사용자의 가입 보험을 불러온다. 조회 → 분석 → 대화 준비
          3단계로 진행 상태를 표시하며, 완료 후 대화 화면으로 전환된다.
 · 화면 : 보험 조회 화면
 · 상태 : 구현 완료

F-03  보장 내용 질의응답
 · 설명 : 자연어 질문을 입력하면 가입 보험을 근거로 답변한다.
          보장 여부, 보장 금액, 보장 기간, 특약명을 함께 안내한다.
 · 화면 : 대화 화면 (좌측)
 · 상태 : 구현 완료

F-04  답변 근거 제시
 · 설명 : 답변과 함께 참조한 문서와 조항을 표시한다.
          파일명·페이지·조항·유사도 점수를 확인할 수 있다.
 · 화면 : 대화 화면 (답변 하단)
 · 상태 : 구현 완료

F-05  답변 표 형식 출력
 · 설명 : 보장 정보를 표로 정리해 출력한다.
          항목·내용 구조로 보장 상태를 한눈에 확인할 수 있다.
 · 화면 : 대화 화면
 · 상태 : 구현 완료

F-06  대화 맥락 유지
 · 설명 : 이전 대화를 반영하여 후속 질문에 답한다.
          "그럼 지금은?"과 같이 생략된 표현도 처리한다.
 · 화면 : 대화 화면
 · 상태 : 구현 완료

F-07  보험정보 입력 및 반영
 · 설명 : 신규 가입 보험을 자연어로 입력하면 보험사·상품명·특약명·
          보장금액·계약일을 추출해 즉시 반영한다. 반영 후 질문부터
          갱신된 보장 내용을 기준으로 답변한다.
 · 화면 : 대화 화면 (우측)
 · 상태 : 구현 완료

F-08  입력 예시 제공
 · 설명 : 사용자별 예시 문구를 버튼으로 제공한다. 클릭 시 입력란에
          자동 입력되며 계약일이 포함되어 있다.
          청년 : 수술비특약 가입 / 운전자보험 가입
          노년 : 간병인보험 가입 / 간병비보험 가입
 · 화면 : 대화 화면 (우측)
 · 상태 : 구현 완료

F-09  입력값 검증
 · 설명 : 계약일이 없으면 경고를 표시하고 전송을 차단한다.
          보험과 무관한 내용은 안내 팝업을 표시하고 저장하지 않는다.
 · 화면 : 대화 화면 (우측)
 · 상태 : 구현 완료

F-10  입력 이력 표시
 · 설명 : 입력한 보험정보를 시각과 함께 목록으로 표시한다.
          항목 클릭 시 전체 내용을 확인할 수 있다.
 · 화면 : 대화 화면 (우측 하단)
 · 상태 : 구현 완료

F-11  사용자 변경
 · 설명 : 다른 사용자로 전환한다. 전환 시 이전 대화가 초기화되어
          항상 동일한 상태에서 시작한다.
 · 화면 : 대화 화면 (상단)
 · 상태 : 구현 완료

F-12  반응형 화면
 · 설명 : 화면 너비에 따라 좌우 배치가 상하 배치로 전환된다.
          PC와 모바일 브라우저를 모두 지원한다.
 · 화면 : 전체
 · 상태 : 구현 완료

3. 사용자 이용 흐름
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1) 배포 URL(https://ins.tricocube.com) 접속
   → 사용자 선택 화면이 표시된다. 로그인 절차는 없다.

2) 체험할 사용자 카드 선택
   → 청년(홍길동) 또는 노년(김순자) 중 선택한다.

3) 가입 보험 조회 (약 3초)
   → 조회 → 분석 → 대화 준비 순으로 진행 상태가 표시된다.

4) 대화 화면 진입
   → 좌측은 대화 영역, 우측은 보험정보 입력 영역이다.

5) 보장 내용 질문
   → 좌측 입력창에 질문을 입력하고 Enter로 전송한다.
   → 답변과 근거가 함께 표시된다.

6) 신규 보험 입력
   → 우측 예시 버튼을 클릭하면 입력란이 자동으로 채워진다.
   → 보내기를 누르면 보험정보가 반영된다.

7) 변경 내용 재질문
   → 좌측에 "그럼 지금은 어떻게 달라졌어?"와 같이 질문한다.
   → 이전 상태와 현재 상태를 비교한 답변이 표시된다.

8) 다른 사용자 체험
   → 상단 "사용자 변경"으로 돌아가 다른 사용자를 선택한다.
   → 이전 대화는 초기화된다.

4. AI 및 데이터 처리 방식
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[AI가 수행하는 역할]

역할 1 · 근거 기반 질의응답
 - 사용자 질문과 가입 보험 정보를 대조하여 답변을 생성한다.
 - 검색된 근거 범위 내에서만 답변하도록 제한하며,
   근거가 없으면 임의로 생성하지 않고 "확인할 수 없음"으로 응답한다.

역할 2 · 보장 상태 해석 및 표현
 - 정형 보험 데이터를 사용자가 이해할 수 있는 문장과 표로 변환한다.
 - 원본 데이터를 변경하지 않고 해석·정리·표현하는 역할로 한정한다.
 - 출력 형식을 보장 개요 표 + 결론 + 추가 안내로 고정한다.

역할 3 · 자연어 보험정보 구조화
 - 자유 형식으로 입력된 보험 내용에서 보험사·상품명·특약명·
   보장금액·계약일을 추출하여 정형 데이터로 변환한다.
 - 변환 결과는 변경 이력으로 기록되어 이전·현재 비교에 사용된다.

역할 4 · 문서 임베딩 및 검색
 - 문서와 질문에 동일한 임베딩 모델을 적용한다.
 - 의미 기반 검색과 키워드 기반 검색을 함께 수행한다.

[사용 모델]
 - 답변 생성 : Gemma-4 E2B (4bit 양자화, 컨텍스트 8192)
 - 임베딩 : BGE-M3 (Dense 1024 / Sparse 250002)
 - 벡터 검색 : PostgreSQL + pgvector (HNSW 인덱스)

 ※ 외부 AI API를 사용하지 않고 자체 서버에서 모델을 직접 구동한다.

[사용 데이터]

 구분 1 · 가입 보험 데이터
  - 내용 : 보험사, 상품명, 증권번호, 계약일, 월 보험료,
           특약명, 보장금액, 보장조건, 보장기간, 보장 상태
  - 용도 : 질의응답의 판단 근거

 구분 2 · 벡터(임베딩) 데이터
  - 내용 : 문서 청크의 Dense·Sparse 벡터
  - 용도 : 질문과 관련된 근거 검색

 구분 3 · 대화 이력 데이터
  - 내용 : 질문과 답변 기록
  - 용도 : 후속 질문의 맥락 유지

 구분 4 · 보험 변경 이력
  - 내용 : 보장 항목의 변경 전후 값과 변경 시각
  - 용도 : 이전·현재 보장 비교 안내

[입력 · 출력 데이터]

 입력
  - 사용자 질문 : 자연어 텍스트
  - 보험정보 : 자유 형식 자연어 텍스트

 출력
  - 답변 : 자연어 텍스트 (표·목록 포함)
  - 근거 : 파일명, 페이지, 조항, 본문 일부, 유사도 점수
  - 반영 결과 : 변경된 보장 항목과 변경 내용

[개인정보 및 민감정보 처리]

 - 본 MVP는 가상 데이터만 사용하며 실제 개인정보를 수집하지 않는다.
 - 보험증권에는 주민등록번호, 질병 이력 등이 포함될 수 있으며
   질병 정보는 개인정보보호법상 민감정보에 해당한다.
 - 외부 AI API를 사용하지 않고 자체 서버에서 모델을 구동하므로
   입력 데이터가 외부로 전송되지 않는다.
 - 실서비스 전환 시 사용자 인증, 접근 제어, 저장 데이터 암호화,
   마이데이터 동의 절차를 적용한다.

5. MVP 검증 방법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[접속 정보]
 - 배포 URL : https://ins.tricocube.com
 - 계정 : 별도 계정 없음. 접속 후 사용자 카드를 선택하면 바로 이용 가능

[검증 절차 1 · 청년 사용자 — 보장 만료 확인 후 신규 가입]

 1) 배포 URL 접속 후 "홍길동 23세" 카드 선택
 2) 보험 조회 완료까지 약 3초 대기
 3) 좌측 입력창에 아래 질문 입력 후 Enter

    입력값 : 목 뒤 종양 수술을 받을 예정인데 수술비 보장을 받을 수 있어?

    예상 결과 :
      - 보장 개요 표 출력
        보험 상품    삼성 어린이보험
        특약명       수술비특약
        보장 종료일  2025년 12월 31일
        현재 상태    만료 (보장 불가)
      - 결론 : 수술비특약이 2025년 12월 31일에 종료되어 보장되지 않음
      - 하단에 참조 근거 표시

 4) 우측 "수술비특약 가입" 버튼 클릭 → 입력란 자동 입력 확인
 5) "보내기" 클릭 → "보험정보가 반영되었습니다" 표시 확인
 6) 좌측 입력창에 아래 질문 입력

    입력값 : 그럼 지금은 수술비 보장이 어떻게 달라졌어?

    예상 결과 :
      - 이전 상태 : 입원/수술 보장 없음
      - 현재 상태 : 3,000,000원 보장 (현대해상)
      - 변경 내용 비교 안내

[검증 절차 2 · 노년 사용자 — 보장 공백 확인 후 신규 가입]

 1) 상단 "사용자 변경" 클릭 후 "김순자 68세" 카드 선택
 2) 좌측 입력창에 아래 질문 입력

    입력값 : 내 보험 중에서 간병인을 사용할 때 보장받을 수 있는 보험이 있어?

    예상 결과 : 간병 보장이 가입되어 있지 않음을 안내

 3) 우측 "간병인보험 가입" 버튼 클릭 후 "보내기"
 4) 좌측 입력창에 아래 질문 입력

    입력값 : 새로 가입한 보험까지 포함하면 간병비 보장이 어떻게 달라졌어?

    예상 결과 :
      - 이전 상태 : 간병 보장 없음
      - 현재 상태 : 1일 15만원, 연간 180일 한도 (KB손해보험)

[검증 절차 3 · 입력값 검증]

 - 우측 입력란에 계약일 없이 텍스트 입력
   → 계약일 안내 문구 표시, 보내기 버튼 비활성화 확인

 - 보험과 무관한 문장 입력 후 보내기
   → "가입하신 보험과 관련된 내용을 입력해 주세요" 팝업 표시 확인

[실행 환경]
 - 권장 브라우저 : Chrome, Edge, Safari 최신 버전
